# 会议分析测试文件

建议新建一个“会议分析”会话后，一次选择并上传三个 TXT：

- `01-星河项目周会-上半场.txt`
- `02-星河项目周会-下半场.txt`
- `03-北辰客户回访.txt`

预期结果：

1. 前两个文件应被识别为同一场“星河项目周会”的分段；
2. 第三个文件应被识别为另一场“北辰客户回访”；
3. 系统只应识别“承诺未闭环风险”，例如缺少截止时间、缺少责任人、验收口径不明确和日期冲突；
4. 每条风险应带原文证据，并自动生成待办；
5. 当前 SMTP 默认关闭，因此邮件状态应显示“未发送（SMTP 未配置）”；
6. 可点击“重新分析”验证强制绕过缓存。
